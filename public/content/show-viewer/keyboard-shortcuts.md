# Bảng Tổng hợp Phím tắt Toàn hệ thống

Tài liệu này tổng hợp toàn bộ phím tắt thao tác nhanh trong phần mềm **Drone Shell Editor**, hỗ trợ tối ưu hóa tốc độ biên đạo, điều hướng dòng thời gian và điều khiển không gian 3D.

---

## 1. Phím tắt Toàn cục & Chuyển đổi Phân hệ

| Phím tắt | Chức năng thao tác |
| :--- | :--- |
| `Ctrl + 1` | Chuyển sang phân hệ **Show Viewer** (Diễn tập & Trình diễn tổng hợp) |
| `Ctrl + 2` | Chuyển sang phân hệ **Animation Formation Editor** (Biên tập Hoạt cảnh Động) |
| `Ctrl + 3` | Chuyển sang phân hệ **Static Formation Editor** (Dựng Đội hình Tĩnh) |
| `Ctrl + S` / `Shift + S` | Xuất lưu kịch bản dự án ra tệp định dạng `.json` |
| `Ctrl + Z` | Hoàn tác (Undo) thao tác vừa thực hiện |
| `Ctrl + Y` | Làm lại (Redo) thao tác vừa hoàn tác |
| `Esc` | Thoát chế độ khóa chuột / Mở Menu tạm dừng và tùy chọn pháo hoa |
| `Shift + Y` | Bật hoặc tắt bảng chẩn đoán hiệu năng kỹ thuật (HUD FPS, GPU, RAM) |

---

## 2. Phím tắt Dòng thời gian (Timeline Sequencer)

| Phím tắt | Chức năng thao tác |
| :--- | :--- |
| `Ctrl + T` | Mở hoặc đóng thanh Dòng thời gian Timeline |
| `Space` | Phát hoặc tạm dừng kịch bản từ mốc thời gian hiện tại của Playhead |
| `Shift + 0` hoặc `)` | Chuyển đổi tuần hoàn các mức thu phóng Zoom Timeline (`25`, `50`, `100`, `200 px/s`) |
| `B` | Đặt mốc nhịp phách (Beat Marker) tại vị trí kim Playhead trên làn âm thanh |
| `Ctrl + C` | Sao chép khối sự kiện hoặc nhóm khối đang chọn |
| `Ctrl + V` | Dán khối đã sao chép vào vị trí kim neo Anchor Head (màu xanh lam) |
| `Delete` / `Backspace` | Xóa toàn bộ các khối sự kiện đang được chọn |
| `Ctrl` / `Shift` + Click | Chọn bổ sung nhiều khối sự kiện (Multi-select) |

---

## 3. Phím tắt Điều khiển Camera Không gian 3D (Viewport)

| Phím tắt | Chức năng thao tác |
| :--- | :--- |
| `W` / `A` / `S` / `D` | Di chuyển vị trí camera (Tiến, Trái, Lùi, Phải) theo hướng ngắm |
| `Q` | Hạ thấp cao độ camera theo phương thẳng đứng |
| `E` | Nâng cao độ camera theo phương thẳng đứng |
| `Chuột phải + Rê chuột` | Xoay tự do góc nhìn camera quanh điểm quan sát |
| `Cuộn chuột giữa` | Phóng to hoặc thu nhỏ khoảng cách tới mục tiêu |

---

## 4. Phím tắt Công cụ Gizmo Biến đổi 3D

Áp dụng khi đang chọn một hoặc nhiều drone trong phân hệ tạo hình:

| Phím tắt | Chế độ biến đổi Gizmo |
| :--- | :--- |
| `W` | Chế độ **Move** (Tịnh tiến khối drone theo các trục tọa độ X, Y, Z) |
| `E` | Chế độ **Rotate** (Quay khối drone quanh tâm xoay Pivot) |
| `R` | Chế độ **Scale** (Co giãn, thu phóng kích thước khối drone) |
