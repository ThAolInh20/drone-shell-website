# Mô phỏng & Trình diễn Drone Pháo hoa (Shell Drone Animation)

<p align="center">
  <a href="README.md">English</a> | <strong>Tiếng Việt</strong>
</p>

**Shell Drone** là một ứng dụng web 3D tương tác cho phép người dùng mô phỏng và dàn dựng các màn trình diễn pháo hoa kết hợp với các màn trình diễn ánh sáng drone đầy tính nghệ thuật. Ứng dụng được thiết kế nhằm mang lại trải nghiệm hình ảnh chân thực, sống động, xây dựng trên nền tảng **Three.js** và **Vite** và được build ra destop app bằng **Electron**.

Phần mềm được xây dựng với 3 modules chính gồm: Ui trình diễn, Ui chỉnh sửa kịch bản drone, và Ui chỉnh sửa formation(đội hình) của drone.

## Các Tính năng Chính

- **Trình diễn**: nơi màn hình chính để mô phỏng trình diễn cho pháo hoa và drone.
- **Ui chỉnh sửa kịch bản drone**: nơi màn hình để chỉnh sửa kịch bản drone, nơi chỉnh sửa các bước chuyển động của mỗi nhóm drone, các chuyển động và các hiệu ứng liên quan.
- **Ui chỉnh sửa formation(đội hình) của drone**: nơi màn hình để chỉnh sửa formation(đội hình) của drone.

## Điểm nổi bật
- Các output đều là .json, giúp cho việc chia sẻ các mô hình drone, animation, trình diễn trở nên cực kỳ linh hoạt và công khai.

## Tải về & Cài đặt (Download & Installation)
Tải ứng dụng chạy trên Desktop (Pre-built Desktop App via Releases)
Để sử dụng trực tiếp công cụ biên tập pháo hoa & drone show dưới dạng ứng dụng Desktop (không cần cài đặt môi trường code phức tạp):
1. Truy cập trang **[GitHub Releases](https://github.com/ThAolInh20/Shell-Drone_3d/releases)** của dự án.
2. Chọn phiên bản (tag) mới nhất và tải xuống file cài đặt dành cho Windows (Ví dụ: `ShellDroneEditor Setup 1.x.x.exe` hoặc file chạy trực tiếp Portable `ShellDroneEditor 1.x.x.exe`).
3. Giải nén file tải xuống và nhấn vào file `.exe` trong thư mục vừa giải nén để bắt đầu sử dụng.
