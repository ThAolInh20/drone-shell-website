# Bảng tổng hợp Phím tắt Toàn hệ thống

Tài liệu này cung cấp toàn bộ phím tắt thao tác nhanh trong phần mềm, giúp tăng tốc quy trình dựng show và điều khiển diễn tập.

---

## 1. Phím tắt Toàn cục & Dự án (Global)

| Phím tắt | Thao tác thực hiện |
| :--- | :--- |
| **`Space`** | Phát hoặc Tạm dừng kịch bản trình diễn từ vị trí kim hiện tại |
| **`Ctrl + S`** / **`Shift + S`** | Lưu kịch bản làm việc vào tệp JSON |
| **`Ctrl + Z`** | Hoàn tác (Undo) thao tác vừa thực hiện |
| **`Ctrl + Y`** | Làm lại (Redo) thao tác vừa hoàn tác |
| **`Esc`** | Mở Menu tạm dừng / Giải phóng con trỏ chuột khỏi góc nhìn camera 3D |
| **`Shift + Y`** | Bật hoặc tắt bảng thông số chẩn đoán hiệu năng FPS & GPU |

---

## 2. Phím tắt Dòng thời gian (Timeline Sequencer)

| Phím tắt | Thao tác thực hiện |
| :--- | :--- |
| **`Ctrl + T`** | Mở hoặc Đóng thanh Dòng thời gian Timeline |
| **`Shift + 0`** hoặc **`)`** | Chuyển đổi các mức thu phóng Zoom Timeline (25px, 50px, 100px, 200px/s) |
| **`B`** | Đặt mốc nhịp beat tại vị trí kim Playhead trên làn âm thanh |
| **`Ctrl + C`** | Sao chép block hoặc nhóm block đang chọn |
| **`Ctrl + V`** | Dán block tại vị trí kim neo Anchor Head (màu xanh lam) |
| **`Delete`** / **`Backspace`** | Xóa toàn bộ các block đang được chọn trên Timeline |
| **`Shift` + Click** | Chọn thêm hoặc bỏ bớt các block vào danh sách chọn (Multi-select) |

---

## 3. Phím tắt Điều khiển Camera & Không gian 3D (Viewport)

| Phím tắt | Thao tác thực hiện |
| :--- | :--- |
| **`W` / `A` / `S` / `D`** | Di chuyển góc nhìn camera (Tiến, Trái, Lùi, Phải) |
| **`Q` / `E`** | Hạ thấp độ cao camera (`Q`) hoặc Bay nâng cao độ (`E`) |
| **Chuột phải + Rê chuột** | Xoay góc nhìn camera tự do trong không gian 3D |
| **Cuộn chuột giữa** | Phóng to hoặc thu nhỏ khoảng cách tới mục tiêu quan sát |

---

## 4. Phím tắt Thao tác Công cụ Gizmo 3D

Khi chọn một hoặc nhiều drone trong Viewport:

| Phím tắt | Thao tác thực hiện |
| :--- | :--- |
| **`W`** | Kích hoạt chế độ **Move** (Di chuyển khối drone theo các trục X, Y, Z) |
| **`E`** | Kích hoạt chế độ **Rotate** (Xoay khối drone quanh tâm Pivot) |
| **`R`** | Kích hoạt chế độ **Scale** (Co giãn hoặc phóng to thu nhỏ khối drone) |
